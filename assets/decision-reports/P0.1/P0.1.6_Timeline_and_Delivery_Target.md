# P0.1.6 — Timeline & Delivery Target

**Decision:** Target a 2–3 day MVP.

**Day 1:** Project decisions, dashboard/UI foundation, routing, FastAPI setup and upload/process/download pipeline.

**Day 2:** Implement and integrate the highest-priority PDF tools.

**Day 3:** Test, fix UI issues, verify responsive behavior, deploy if a suitable free host is available, and complete essential documentation.

**Scope-control rule:** If a tool cannot be completed and verified within the target, defer it rather than claiming it works.

**Acceptance criteria:**
- The core end-to-end workflow works locally.
- Main supported tools pass basic valid/invalid input tests.
- Deployment and free-host constraints are recorded.
- The release README explains how to run the project.
