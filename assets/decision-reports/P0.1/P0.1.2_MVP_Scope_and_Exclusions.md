# P0.1.2 — MVP Scope & Exclusions

**Decision:** Build a small, usable web MVP within a target of 2–3 days. Prioritize core PDF tools before optional or complex features.

**Initial priorities:** Images to PDF, Merge PDFs, Split/Extract Pages, PDF to Images, Rotate Pages, Extract Text and basic Compression where feasible.

**Conditional tools:** Word/Excel/PowerPoint to PDF, because they may require LibreOffice or another system dependency.

**Optional/post-MVP:** AI PDF Summarizer, Chat with PDF, advanced workflows and features that threaten the delivery target.

**Excluded from MVP:** Accounts/subscriptions, persistent cloud document library, native Android app, paid APIs and heavyweight AI hosting.

**Reason:** A smaller verified release is more valuable than many unfinished tools.

**Acceptance criteria:**
- Each included tool works end-to-end and is tested.
- Deferred tools are clearly recorded and are not presented as complete.
