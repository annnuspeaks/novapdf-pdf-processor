# P0.1.3 — Free & Open-Source Policy

**Decision:** Use free/open-source software and no paid APIs or paid AI services.

**Cost target:** ₹0 for software licences and AI API usage.

**Implementation approach:** Prefer local processing and established open-source libraries. Use free hosting only if its limits support the selected workload.

**AI rule:** AI is optional. Consider a lightweight local model only if it runs practically on available hardware and fits the time limit. Core PDF operations must not depend on AI.

**Important limitation:** Zero API/software cost does not guarantee zero hosting, hardware, bandwidth or storage cost. Free hosting can impose sleep, memory, time and file-size limits.

**Acceptance criteria:**
- No paid API key is required to run core tools.
- No secrets are exposed in frontend code.
- Any hosting/runtime limitations are documented.
