# P0.1.4 — Lightweight Web-First Architecture

**Decision:** Use a small frontend and a reusable backend; avoid unnecessary services and dependencies.

**Initial stack:**
- Frontend: React + Vite
- Styling: CSS and CSS variables
- Routing: React Router
- Backend: Python + FastAPI
- PDF processing: pypdf; add PyMuPDF or pikepdf only when needed
- Image processing: Pillow

**Workflow:** Dashboard card → dedicated tool page → input/options → processing → same-page result → direct download.

**Reason:** This stack supports fast development and keeps processing logic reusable for a future Android client.

**Acceptance criteria:**
- Each implemented tool has a dedicated route.
- Output is shown on the same page, not a separate result page.
- Generated files can be downloaded through the browser.
- Dependencies remain limited to what implemented features require.
