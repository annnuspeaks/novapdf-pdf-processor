# P0.1.1 — Project Name & Purpose

**Decision:** The project name is **Nexora PDF Tools**.

**Purpose:** Build a lightweight, Nexora-inspired web dashboard containing practical PDF utilities. Each implemented tool has its own page, with input, processing, results and download on that same page.

**Reason:** A clear, focused product identity keeps the MVP easy to understand and build.

**In scope:** PDF utilities, tool-card dashboard, dedicated tool pages, same-page results and downloads.

**Out of scope for MVP:** A broad all-purpose document platform or complex enterprise features.

**Acceptance criteria:**
- The project is consistently named Nexora PDF Tools.
- The dashboard explains the tool collection clearly.
- Each implemented tool is reachable from its dashboard card.
